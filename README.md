# 🎮 VideoGame API

A simple **.NET 9 Web API** for managing video game data, built with **Entity Framework Core** and **SQL Server**.

---

## 🚀 Technologies Used

- [.NET 9](https://dotnet.microsoft.com/)
- [ASP.NET Core Web API](https://learn.microsoft.com/aspnet/core)
- [Entity Framework Core 9](https://learn.microsoft.com/ef/core/)
- [SQL Server](https://www.microsoft.com/sql-server)
- [Scalar.AspNetCore](https://github.com/RicoSuter/Scalar) (for interactive API documentation)
- OpenAPI / Swagger

## ⚙️ Setup Instructions
### 1️⃣ Clone the repository
```
git clone https://github.com/your-username/VideoGameApi.git
cd VideoGameApi
```

### 2️⃣ Configure the database connection

Open the appsettings.json file and set your connection string:
```
"ConnectionStrings": {
  "DefaultConnection": "Server=localhost;Database=VideoGameDb;Trusted_Connection=True;TrustServerCertificate=True;"
}
```

### 3️⃣ Apply database migrations
```
dotnet ef database update
```

### ▶️ Run the Application
```
dotnet run
```


The API will start at:
```
https://localhost:7123
http://localhost:5123
```

## 📚 Main Endpoints

| Method | Endpoint              | Description                   |
| :----- | :-------------------- | :---------------------------- |
| GET    | `/api/videogame`      | Get all video games           |
| GET    | `/api/videogame/{id}` | Get a video game by ID        |
| POST   | `/api/videogame`      | Add a new video game          |
| PUT    | `/api/videogame/{id}` | Update an existing video game |
| DELETE | `/api/videogame/{id}` | Delete a video game           |
